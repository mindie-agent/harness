# mindie-harness 0.1.0: Unified Pure-Stdlib Shared Substrate for All 7 Native Host Plugins

[中文](harness-0.1.0.md)

`mindie-harness v0.1.0` is the initial formal release of the zero-heavy-dependency, pure-Python-stdlib shared plugin substrate (`mindie_harness`) powering all 7 MindIE Agent native host plugins (`codex`, `cc`, `kimi`, `dsh`, `agy`, `wb`, `oc`):

- **Cross-Platform Windowless Process & Nested Win32 Job Supervision (`mindie_harness.process`)**: Spawns Windows child processes via `CreateProcessW(CREATE_SUSPENDED | CREATE_NO_WINDOW | CREATE_UNICODE_ENVIRONMENT | CREATE_NEW_PROCESS_GROUP)` and attaches a non-inheritable nested Job Object (`KILL_ON_JOB_CLOSE`, `512 MiB` control-plane memory cap, and background priority throttling) prior to `ResumeThread`, forbidding `CREATE_NEW_CONSOLE` and `DETACHED_PROCESS`. Verifies `IMAGE_SUBSYSTEM_WINDOWS_GUI` PE headers across both venv and `pyvenv.cfg` base binaries for scheduled/GUI workers, drains inherited stdout/stderr pipes to EOF up to deadline before process-group cleanup on POSIX/Win32, and skips `.exe`/`MZ`/DrvFS shims on WSL2.
- **Two-Generation (`Active + Rollback`) `.inuse`-Leased Atomic Runtime Lifecycle (`mindie_harness.runtime`)**: Enforces a `2.5 GiB` disk floor and same-volume `UV_CACHE_DIR` before single-venv candidate builds, commits `<host>.json` atomically last, and retires superseded generations via non-`FILE_SHARE_DELETE` `.inuse` leases plus two-stage `.trash` directory renames (`<= 2` retained generations).
- **Dual-Framing Concurrent MCP Gateway & Receipt Honesty (`mindie_harness.mcp`)**: Supports both `Content-Length` and JSONL framing with non-blocking read/status/cancel execution, enforcing `P2.7` zero-binding deterministic tool pass-through alongside `P2.1` manual `/mindie-agent` admission for `knowledge_*`, and preserving `isError=False` with `receipt_warning` + `receipt_unconfirmed=True` on post-success local receipt failures.
- **Consolidated Pure-Stdlib RSI Engine & Deterministic Cold Seed (`mindie_harness.rsi` & `mindie_harness.bootstrap`)**: Hosts linked-worktree-safe `experiment_ledger` and `rsi_loop` (`mindie-rsi-loop/2`), and ships reproducible `< 60 KB` `dist/mindie-harness-seed.pyz` + `dist/seed-lock.json` (`mindie-harness-seed/1`).
