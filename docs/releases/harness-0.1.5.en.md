# mindie-harness 0.1.5: 9-Domain Knowledge Provisioning, Cross-Component Duplex Contracts & `selftest` Usability Gates

[中文](harness-0.1.5.md)

`mindie-harness v0.1.5` is now available. While preserving `API_VERSION = 1` and a 100% pure-stdlib runtime (`dependencies = []`), this release closes the post-consolidation contracts across all 8 shared components and 7 native host plugins atop #7, and embeds both pre-cutover candidate probing and full-stack zero-mock verification (`mindie_harness.selftest`):

- **Content-Addressed 9-Domain Knowledge Provisioning & Revocation Permanence (`runtime/knowledge_binding.py` · `mcp/knowledge_rpc.py` · `mcp/knowledge_schemas.py`)**: Provisions content-addressed `<config_home>/engines/<host>/<20hex>/<domain>.engine.json` across all 9 public corpora via `domain_catalog.prepare` and retires replaced owners with `retire_changed(..., include_default=True)`, eliminating `.retired` in-place deadlocks and zero-Git `FileNotFoundError`s; defaults standalone/scannerless installs to `capture_mode="disabled"` for immediate out-of-the-box public reads; enforces consent + `project_roots` + irreversible `inactive` session revocation across `run_stop_capture` and `knowledge_distill`; and completes batch `explain(refs=...)`, paged `query(continuation=...)`, and `450s` inner deadline budgets.
- **Duplex Child IPC & Cross-Component Contract Alignment (`mcp/router.py` · `mcp/gateway_dispatch.py` · `component_commands.py` · `mcp/doctor.py` · `sharing.py`)**: Removes request-path `claim_bind` write locking and allows schema-declared `session_id` handle properties; switches bootstrap-to-venv child hops to `stdin`/`stdout` framed JSON (eliminating `sys.argv` secret exposure, Win32 `32 KB` command-line limits, and parent `sys.path` shadowing); wires `remote_dev` `session_scope` per-call ledger isolation; adds `stdin_json` (`rsi_loop`, `experiment_ledger`) and `stdin_text` (`debugger`), switches `sim` to `mindie_sim.cli`, defaults empty `npu_top` calls to `["--json", "servers"]`, fixes bootstrap-interpreter `mindie_doctor` dispatch, and preserves locked `mindie-community.json` / `reporting_revision` state in `sharing.py`.
- **Windows `pythonw.exe` Auto-Repair, Daemon Job Breakaway & Dual-Mode `selftest` (`runtime/builder.py` · `bootstrap/seed_main.py` · `process/win32.py` · `selftest.py`)**: Repairs `uv <= 0.12.3` console-trampoline `pythonw.exe` (`PE Subsystem == 3`) from base CPython's `venvwlauncher.exe` before dual-layer `Subsystem == 2` verification; enables Win32 Job breakaway for persistent `coordinator` daemons; and ships `mindie-harness selftest --mode candidate` (`< 2.5s` inside `prepare_candidate_runtime` prior to `os.replace`) plus `--mode full` (exercising both framings and both `.venv` & stdlib-bootstrap topologies across all MCP surfaces and components in 3-OS CI with `MINDIE_REQUIRE_FULLSTACK=1`), alongside refreshed `dist/mindie-harness-seed.pyz` / `dist/seed-lock.json`.
