# mindie-harness 0.1.2: Silent Default-On MCP Routing (`P2.7` / `P2.8`) & Consent-Gated Cold `Stop` Hooks

[中文](harness-0.1.2.md)

`mindie-harness v0.1.2` is a patch release of the zero-heavy-dependency, pure-Python-stdlib shared substrate (`mindie_harness`) powering all 7 MindIE Agent native host plugins (`codex`, `cc`, `kimi`, `dsh`, `agy`, `wb`, `oc`), unifying silent default-on execution across every MCP surface and tightening cold-start hook boundaries:

- **Silent Default-On & Lock-Free Anonymous Fast Path (`mindie_harness.mcp.router.MCPRouter`)**: Retires the legacy manual session-admission gate and `admission.sqlite3` pre-check on `knowledge_*`; all registered tools across `remote`, `tools`, `components`, `knowledge`, and `all` (preserving explicit `tools=[]`) are exposed directly in `tools/list` on cold start and execute over standard `tools/call` with zero `_meta`. Optional bind IDs are extracted solely from host `_meta` (never model-controlled arguments), and anonymous calls skip `BindStore.claim_bind` SQLite locks entirely while falling back to `{host}-conn-{connection_id[:12]}`.
- **Single-Point Schema Normalization, Forged-Identity Guard & Iron Rule 2 Pre-Dispatch Timeouts**: Normalizes `inputSchema.properties` and `inputSchema.required` once in `MCPRouter.__init__` by stripping `CORRELATION_STRIP_KEYS` (`request_nonce`, `_mindie_bind_id`, `context_file`) while still stripping legacy caller arguments, enforcing `FORGED_IDENTITY_KEYS` rejection and `rsi_explore.parse_args`, keeping `except TimeoutError: raise` before `OSError` handlers (Principle 14), and reporting `submission_state="not_sent"` on pre-dispatch `TimeoutError` vs `"uncertain"` once the tool handler has started.
- **Read-Only Fast Lane & Idempotent Mutation Receipts**: Routes `knowledge_query` and `knowledge_explain` on the lock-free read-only fast lane (completing concurrently even when mutation workers are saturated) while applying `RemoteReceipts` duplicate-replay protection and Receipt Honesty (`isError=False` + `receipt_warning` + `receipt_unconfirmed=True`) to non-readonly mutating tools (`knowledge_distill`, `knowledge_sync`, `knowledge_feedback`, and remote/component mutations).
- **Consent-Gated Cold `Stop`/`SessionEnd` Hooks & Synchronized Seed (`mindie_harness.bootstrap`)**: Removes the legacy 32 MiB prompt scanner on cold `pre-invocation`/`user-prompt-submit` hooks and gates `stop`/`session-end` on saved sharing consent (`mindie-community.json` / `mindie-consent.json` with `enabled is True` and event workspace inside authorized `project_roots`) rather than `admission.sqlite3` file existence; bumps `pyproject.toml`, package metadata, bilingual docs, and `dist/mindie-harness-seed.pyz` / `dist/seed-lock.json` (`mindie-harness-seed/1`) to `0.1.2` (`API_VERSION = 1`).
